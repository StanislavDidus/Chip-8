# Gorgeous "Tick" Chip8 game

# Registry Layout
# V0 - score
# V2 - game state
# 0 - menu
# 1 - game
# V3 - free
# V1 - movement direction
# 0 - right
# 1 - left
# 2 - down
# 3 - up
# V4 - target pos x
# V5 - target pos y 
# V6 - is circle active
# - 0 - not active
# - 1 - active
# V7 - circle pos x
# V8 - circle pos y
# V9 - circle speed (1 move per n frames)
# VA - circle step (1 pixel per move)
# VB - circle range (3 pixels)
# VC - temp data for circle collision detection
# VD - temp data for circle collision detection
# VE - temporary data
